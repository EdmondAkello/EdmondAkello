- 💻 **Engineering Software** — Python, QGIS plugins, desktop applications, computational tools, and workflow automation.

## Featured Projects

### [QEHT — Engineering Hydrology Toolkit](https://github.com/EdmondAkello/qeht)
QEHT is a QGIS Processing toolkit that develops a connected workflow from digital elevation models to hydrological networks, catchment characteristics, road-drainage assessments, and structured engineering outputs.

### [LandXML Road & Terrain GIS Tools](https://github.com/EdmondAkello/landxml_tin_to_geotiff)
A native QGIS Processing provider for converting engineering design data into GIS-ready terrain and vector datasets.
